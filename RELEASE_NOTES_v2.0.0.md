# Quantum Research Portfolio v2.0.0

## Field-First Research Portfolio

Release Date: 2026

---

## Overview

Version 2.0.0 represents the first unified Field-First release of the Quantum Research Portfolio.

This release consolidates the portfolio into a single research structure encompassing:

- Field-First Interpretation
- Detector-Plane Imaging (DPI)
- Quantum Measurement Stack (QMS)
- Detector-Plane Causality

while preserving historical research artifacts and prior publications in archival form.

---

## Major Changes

### Portfolio Consolidation

A unified repository structure was established for all active research programs.

Components include:

- Field-First Interpretation
- Detector-Plane Imaging
- Quantum Measurement Stack
- Detector-Plane Causality
- Foundations
- Archive

---

### Field-First Migration

The active framework has been migrated to a Field-First terminology and organizational model.

Changes include:

- Replacement of legacy Imprint-era terminology in active repositories
- Introduction of Field Dynamics as the primary pre-measurement framework
- Alignment of documentation across DPI and QMS
- Consistent terminology across benchmarks, papers, and repository documentation

---

### Detector-Plane Imaging (DPI)

Updates include:

- Documentation alignment with the Field-First framework
- Cleanup of legacy terminology
- Consolidation of repository, runtime, and publication assets
- Preservation of reproducible simulation workflows

---

### Quantum Measurement Stack (QMS)

Updates include:

- Field-First terminology migration
- Benchmark documentation updates
- QMCTB framework alignment
- Documentation cleanup across DAQ, diagnostics, detector, QCS, and benchmark layers

Benchmarks preserved:

- QMCTB-01 — Detector-Plane Causality
- QMCTB-02 — Detector Coherence Transfer Function
- QMCTB-03 — Detector-Conditioned Observability
- QMCTB-04 — Framework Development

---

### Detector-Plane Causality

Updates include:

- Consolidated publication package
- Organized handout and submission materials
- Integration into the unified portfolio structure
