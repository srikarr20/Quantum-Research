# Contributing and Extending Quantum-Research

Quantum-Research is published as an open research foundation.

## Core research integrity

The validated research, experiments, evidence, papers, and tagged releases in this repository represent the author's controlled research record.

External users should not modify or overwrite these materials when extending the work.

## How to extend the research

Anyone is free to:

- clone this repository;
- fork this repository;
- use a tagged release as a research baseline;
- build new experiments, adapters, models, integrations, applications, or derivative research;
- create independent repositories that depend on or extend Quantum-Research;
- cite the original repository and archived release.

No pull request to this repository is required in order to build an extension.

## Recommended extension model

Use this repository as an upstream research foundation.

For example:

    git clone https://github.com/srikarr20/Quantum-Research.git

Extensions should preferably live in a separate repository so that the original validated research record remains unchanged.

## Research provenance

When extending this work, record:

- the Quantum-Research release or Git commit used;
- the QMS Platform release if applicable;
- changes introduced by the extension;
- new datasets or experimental conditions;
- validation evidence produced by the extension.

This preserves reproducibility and clearly distinguishes original research from derivative work.

## Upstream contributions

Pull requests may be considered separately, but are not required for independent use or extension of this research.
