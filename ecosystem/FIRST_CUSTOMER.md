# First Customer Strategy

## Objective

Generate the first paid engagement using existing ecosystem assets.

Success is defined as:

- First customer
- First invoice
- First payment
- First case study

---

# Initial Customer Segment

## Priority 1

Academic Research Labs

Why:

- Existing relationships are easier
- Lower procurement friction
- Immediate need for review and validation

---

## Priority 2

Instrumentation and Detector Teams

Why:

- Direct alignment with DPI and QMS
- Strong validation requirements

---

## Priority 3

Scientific Software Teams

Why:

- Need benchmarking and technical review
- Can become recurring customers

---

# First Offer

## Independent Technical Assessment

Customer Provides:

- Paper
- Dataset
- Software
- Experimental Results

QAG Provides:

- Technical Review
- Validation Assessment
- Benchmark Analysis
- Recommendations

Deliverable:

PDF Assessment Report
