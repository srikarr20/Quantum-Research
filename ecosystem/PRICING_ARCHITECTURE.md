# QAG Pricing Architecture

## Principle

Price is based on outcome complexity, not hours.

The objective is to establish repeatable commercial transactions.

---

# Tier 1

## Rapid Assessment

Target Customer:
- Students
- Researchers
- Small Labs

Inputs:
- Single paper
- Small dataset
- Small repository

Deliverables:
- Assessment Summary
- Findings Report
- Recommendations

Purpose:
- Entry point into ecosystem

---

# Tier 2

## Validation Assessment

Target Customer:
- Research Groups
- Instrumentation Teams

Inputs:
- Experimental data
- Measurement workflows
- Detector outputs

Deliverables:
- Validation Report
- Technical Findings
- Recommendations

Purpose:
- Core ecosystem service

---

# Tier 3

## Benchmark Evaluation

Target Customer:
- Scientific Software Teams
- Research Consortia

Inputs:
- Models
- Software
- Pipelines
- Methodologies

Deliverables:
- Benchmark Report
- Comparative Analysis
- Performance Summary

Purpose:
- Trust generation

---

# Tier 4

## Strategic Assessment

Target Customer:
- Startups
- National Labs
- Government Programs

Inputs:
- Technology
- Architecture
- Research Program

Deliverables:
- Technical Due Diligence
- Risk Assessment
- Strategic Recommendations

Purpose:
- High-value engagements

---

# Pricing Rule

First Objective:
Acquire Reference Customers

Second Objective:
Acquire Repeat Customers

Third Objective:
Optimize Pricing

Never optimize price before achieving repeat demand.
