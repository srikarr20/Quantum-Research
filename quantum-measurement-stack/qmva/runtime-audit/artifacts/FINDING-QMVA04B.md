# QMVA-04B

Variance Reduction Under Noise

Objective:

Compare binary threshold estimation
against confidence-aware estimation.

Result:

At elevated detector noise levels,
confidence-aware estimation exhibits
lower variance than binary thresholding.

Examples:

Noise = 1e-4
Binary Std = 0.001328
Prob Std   = 0.000911

Improvement = 31.4%

Noise = 2e-4
Binary Std = 0.001397
Prob Std   = 0.000939

Improvement = 32.8%

Interpretation:

Detector-plane confidence provides
a stabilizing effect under noisy
measurement conditions.

Conclusion:

Detector-plane information is not
only present but operationally useful
for improving measurement robustness.
