# EVIDENCE-014

## Title

Abstraction Compression Index

## Audit

QMVA-03

## Purpose

Measure representation compression between
detector-plane measurements and user-visible
state assignments.

## Detector Representation

Per shot:

(I,Q)

Continuous two-dimensional measurement space.

## Output Representation

Per shot:

Ground
or
Excited

Binary classification.

## Observation

The detector records a continuous coordinate
within an IQ plane.

The user receives only a discrete state label.

## QMVA Interpretation

A substantial representation reduction occurs
at the classification boundary.

The measurement stack preserves classification
accuracy while reducing measurement-space
visibility.
