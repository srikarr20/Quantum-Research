# EVIDENCE-013

## Title

Visibility Retention Index

## Audit

QMVA-03

## Definition

VRI = 1 - Average Classification Error

## Inputs

Ground Error  = 0.0103

Excited Error = 0.08564

Average Error = 0.04797

## Result

VRI = 0.95203

## Interpretation

Approximately 95.2% of detector-plane visibility
is retained through the classification process.

Only 4.8% of visibility is lost due to
threshold-based state assignment.

## QMVA Interpretation

The detector-plane measurement distributions
remain highly separable after projection.

The classification boundary introduces
limited information compression for this
dataset.
