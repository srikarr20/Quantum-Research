# QG-05: Excitation Path Multiplicity (EPM)

## Objective

Determine whether multiple distinct excitation histories
can converge to the same final quantum state.

## Research Question

Can history information exist that is not represented
by the final quantum state alone?

## Metric

Excitation Path Multiplicity (EPM)

EPM(S) =
Number of distinct excitation histories
that produce equivalent final state S.

## Example Candidate

Path A:
|0> → H

Path B:
|0> → H → X

Potential Result:

Final State(A) = Final State(B)

EPM(|+>) = 2

## Interpretation

State Information
≠
History Information
