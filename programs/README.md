# QAG Programs

Programs are autonomous ecosystem units operating under QAG governance.

Each program may develop:

- Research
- Infrastructure
- Products
- Services
- Participants
- Revenue Streams

while remaining interoperable with the broader ecosystem.

## Governance

Programs operate independently while adhering to QAG ecosystem principles.
